# Python Media Catalogue

A simple Python application for managing movies and TV series using Object-Oriented Programming (OOP).

## Features

- Add movies and TV series to a catalogue.
- Display movies and TV series separately.
- Store titles, release years, directors, and durations.
- Track seasons and episodes for TV series.
- Validate inputs and handle errors.

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

## Python Concepts

- Classes and Objects
- Inheritance and Polymorphism
- Method Overriding
- `super()` and `isinstance()`
- Exception Handling
- Custom Exceptions
- List Comprehension
- Magic Methods (`__init__`, `__str__`)

## How to Run

1. Clone or download this repository.
2. Make sure Python 3 is installed.
3. Run the Python file:

```bash
python media_catalogue.py
```
